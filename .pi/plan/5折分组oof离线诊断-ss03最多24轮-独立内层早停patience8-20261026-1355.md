# 5折分组 OOF 离线诊断计划

## 一、目标与本次授权

生成原始 **7,852 张 train 图片各一次样本外预测**，为后续研究错标、漏标定位提供独立性更好的预测依据。本轮先检验 OOF 数据链路和预测表现，**不改标签、不自动判错、不训练第六个全量模型、不继续已止损的热区裁剪方向**。

学习者已经明确确认：
- 历史 **SS03**：YOLOv8n 从零初始化，最多24轮，batch16、640、workers2、device0；mosaic=1、mixup=0、copy_paste=0、close_mosaic=10。
- 早停 **patience=8**。
- 使用与外折隔离的**内层早停监控集**。
- 按 MVI 分组，完全同图的组绑定；折分seed=42，trainer seed=0。
- 本次允许 AI 写完整的独立 OOF 执行器、测试和配置，并执行五次训练及对应外折预测；允许读取既定环境 `E:\anaconda\envs\dl-3lc\` 的运行依赖。

本方案使用普通 Ultralytics，**仅作独立离线数据诊断**。项目 `RULES.md` 要求竞赛训练使用官方入口及3LC；学习者批准独立诊断不等于主办方批准，产物不自动用于竞赛、集成、伪标签或提交。依据 AGENTS §5.2 在 `PROJECT_LOG.md` 记录本次限定授权；不修改 AGENTS、RULES 或官方入口。

## 三、划分与信息隔离

### 3.1 外层5折

只用原train清单及标签统计划分；**val966不参与训练、早停、最佳模型选择、折分平衡或调参，test不读取**。

1. MVI组为不可拆分单位；跨组若发现完全相同图片哈希，用连通分量绑定后分配。
2. seed=42，以固定、可复现的贪心平衡规则分配五个外折，综合图片数、四类框数及四类有标注图片数；平衡是尽量而非强行拆组达到。
3. 在看到任何新模型结果前冻结折分、平衡目标/结果和所有图片身份，不按预测表现重新折分。
4. 校验五个外折两两无图片/组/完全同图哈希交叉，外折并集恰好7,852图，每图只出现一次。

### 3.2 每折内层早停集

对该外折以外约80%的MVI组，再按组留出约10%的**剩余图片量**作为monitor，其余作为fit：整体约 **72% fit / 8% monitor / 20% outer**，数量以实际组分配为准。

- 内层分配仍用seed42的确定性流程，兼顾四类覆盖，不拆MVI或完全同图绑定组件。
- 每折fit、monitor、outer三者组/路径/完全同图哈希均互斥。
- 每折fit与monitor均须有四类标注，集合非空；若约定约束无法满足，停止报告具体情况，不擅自换种子或拆组。
- monitor可以参与早停和best选择；outer不得进入训练DataLoader、逐轮验证或best选择。
- 每张图片在自己作为outer的那一折没有参与该模型的梯度更新或早停。它在其他折参与训练/monitor属于正常OOF设计。
- 内层只是一份监控集，**不是再嵌套训练5折**，总共仍仅五个模型；不做best轮数确定后的额外重训。

## 四、固定训练与预测配置

### 4.1 训练

| 项目 | 设置 |
|---|---|
| 架构/初始化 | YOLOv8n、环境内本地yolov8n.yaml、4类、每折独立随机初始化；不加载任何历史best/last或外部预训练权重 |
| epochs / patience | 最多24 / 8，直接接入trainer，运行时核验 |
| batch / imgsz / device / workers | 16 / 640 / 0 / 2 |
| trainer seed / deterministic | 0 / true |
| 增强 | mosaic=1，mixup=0，copy_paste=0，cutmix=0，close_mosaic=10，其余保持当前库SS03对应默认值并完整归档 |
| 优化器 | 保留历史optimizer=auto与lr0请求值.01；根据当前库四类、24轮和样本量预期实际为AdamW、lr=.00125、beta1=.9；保存并检查实际参数，不把请求lr0当实际学习率 |
| 精度 | 保留历史AMP设置；隔离环境下禁止外部权重AMP探测，通过仅本进程的明确适配跳过该探测，记录“未运行外部权重AMP一致性检查”，不声称该自检通过 |
| 其余 | pretrained=false、resume=false、cache=false、rect=false、compile=false、无DDP/并行折、无自动batch/设备切换 |

每折独立子进程，使用已安装的Python3.12.15、torch2.14.1+cu130、Ultralytics8.4.165及RTX4060 Laptop GPU；预检发现版本、GPU或配置不符则停止，不安装/升级或自动换设备。

**早停口径**：每轮只评估monitor，依据库原生fitness，8轮没有刷新有效最好值则停止；保留零fitness初期特殊行为及相同分数的库行为，不宣称patience8一定会早停。记录每轮fitness、原生stopper的best_epoch、best.pt实际对应轮次与最终结束原因。提前停止可能发生在关闭mosaic之前，按实际发生记录，不自动延长训练。

若loss/fitness/权重出现NaN/Inf，运行时适配直接报错并停止，禁止库自动加载last回滚恢复或重做训练轮次；不更改依赖文件。

### 4.2 外折预测

每折训练结束并核验成功后，冻结该折best.pt及SHA256，再用它只预测本折outer图片：
- 原图全图，640输入，不裁剪、不TTA、不模型集成。
- 四类全部保留，预测conf=.001、NMS IoU=.7、max_det=300、agnostic_nms=false、batch1、device0、FP32；这些仅是本次预测存储口径，不是自动补标阈值。
- 保存原始浮点conf、类别、原图xyxy、图片/标签哈希、所属outer折、模型哈希、输入尺寸及生效参数；包含零预测图片的空记录，不漏掉“没有框”的图片。
- 每张图片仅来自自己的一个外折模型；不对多个模型结果投票或平均。
- outer原标签只允许在权重冻结后的离线评估/浏览环节读取，不反向影响该折训练、权重选择或参数。

## 七、执行预算与失败策略

- 顺序执行fold01→fold05，**最多5次训练入口启动**，每折最多24轮；无“试跑一轮”或额外第六次训练。
- 每折训练子进程上限45分钟，外折预测上限15分钟；整批含准备和核验上限6小时，不把安全超时写成早停收敛。
- 预计正常计算量仍为数小时，参考此前2.5～4小时量级；当前约72%fit、内层监控、普通Ultralytics与历史入口不同，且早停未必触发，时间估计非保证。
- 一折失败、超时、GPU/OOM、NaN、来源漂移或记录校验失败，停止整批，保留已完成折与部分预测；不续训、不自动重试、降低batch、换设备/模型、补跑或调整参数。
- 训练/预测前分别创建独占启动标记和锁，防重复启动；崩溃后保留锁。只读verify不触发训练。
- 执行使用宿主后台任务监督，持续落盘进度；对话结束不伪装为已完成。只有实际完成并验收后才报告成功。

### 阶段2：五折训练与预测
- 每折在入口前验证其fit/monitor/outer隔离、配置/代码/数据哈希。

- 合并后确认7,852个唯一图片ID，各自对应正确outer折，零输出图片仍有记录；模型哈希/输入来源完整，fold数据无泄漏。
