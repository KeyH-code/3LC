# Train 标签清洗 A/B 实验设计讨论稿

## 0. 本次范围与授权

本次只评估实验设计，不修改 train/val，不运行模型，不安装依赖，不改训练入口或 AGENTS/RULES，不提交 Git。批准此稿仅表示认可讨论框架，**不授权执行清洗、推理或训练**。具体清洗范围、对照配置、随机种子、运行次数与预算须由学习者另行确定。

接受学习者的工作假设：Agent 视觉审核总体具有可用性，纠正样本多于改错样本。无需为此要求学习者重新逐图验收。该假设不等于已经证明清洗能改善泛化：少数严重错标、类别分布、框质量和 train/val 标注口径可能改变实际收益。

## 1. 已核实的现状

- 实际视觉审核为两批共 38 张；全量 OOF 数值分歧分析不等于全量视觉审核。
- 当前明确修改清单：22 张标签文件，14 个漏框（car 5、van 2、bus 7）和 8 个错类（car→van 5、van→car 1、truck→van 1、van→bus 1）。
- 其余已审案例：13 例保留原标、1 例不应标注、2 例待明确。没有额外一批已经完成视觉审核、明确应改而未计入的样本。
- 8 个错类原框位置已核对；14 个漏框的候选坐标还须视觉核对边界。允许 Agent 对清楚的目标定稿，不要求全部重新人工验收；困难目标进入待定清单。
- 修改 22/7852 张约占 0.28%；新增 14/72273 个框约占 0.019%。整体指标变化可能很小；无明显变化不能直接否定清洗思路。
- 可作为历史参照的 baseline：`reports/baseline-starter-20261024/RESULT.md`、`args.yaml`、`MODEL_ARTIFACTS.json`。历史 best.pt 路径仍存在，本次仅检查存在性，未重新加载模型或验证权重哈希。
- 历史 baseline 是 YOLOv8n 随机初始化、10 epochs、batch16、640、device0、workers2、train7852、固定 val966；不是 5 折 SS03 OOF 的训练配置。
- 历史实际生效行为与 YAML 字面值不同：trainer seed0、patience100；optimizer=auto 实际 AdamW(lr=.00125,momentum=.9)；10轮配合 close_mosaic=10 在开始即关闭 mosaic。若复现该对照，不能顺便修复这些行为，否则不再只有标签变化。

## 2. 要检验的命题

### 主命题

在训练配置、初始化方式、图片集合和固定 val 不变时，用冻结清洗标签训练的模型，其固定 val 检测质量是否优于原始标签训练模型。

### 辅助命题

在相同标签参照、相同评估器及相同工作点下，train 与 val 的指标差距是否变化，变化由 val 提升还是 train 下降造成。

**不将“差距缩小”单独定义为成功。** train 下降也可缩小差距；清洗增加漏标框后，train 指标还可能上升、差距反而扩大。两者都不能替代固定 val 的改善证据。

历史报告供现状参考（并非已统一固定 P/R 阈值的新评估）：

|指标|train|val966|train减val|
|---|---:|---:|---:|
|Precision|89.38%|89.21%|0.17个百分点|
|Recall|83.95%|69.20%|14.75个百分点|
|AP50|91.13%|78.48%|12.66个百分点|
|AP50–95|72.74%|60.68%|12.06个百分点|

Precision 本来已接近，主要观察 Recall/AP 的变化更有信息量，但不预设必须以哪种变化收场。

## 3. 清洗范围和不确定样本

### 建议的首轮规则（待学习者裁定）

- 已验收22张进入清洗清单；其他经实际视觉审核、证据明确的 Agent 纠正同样可进入，不要求重新人工逐项批准。
- Agent 结论为“保留原标”或“不应标注”的对象不产生修改。
- 低置信、类别/区域规则不明、框对应不明、边界无法定稿的对象保留原标签并登记为 deferred；保留不代表原标已被证明正确。
- 不通过“请给更高置信答案”来强迫定案。只有新增可核查视觉证据、明确规则或目标对应后，才可改变其状态。Agent 无校准的错误概率，不设未经决定的数值置信门槛。
- 先冻结清洗清单，再训练；不得看到 val 分数后临时增加/撤回修改来追分。

目前待定：首批案例1特殊车辆规则、第二批案例19黄色van与所选框对应。首轮保守保留可避免这两例影响主对照。

### 若要扩大清洗

需先确定新增视觉审核范围：剩余候选、某些场景，还是全部 train。实际看过后仅采用明确结论；未审 OOF 预测不能直接转标签。新增清洗改变了实验版本和修改数量，必须重新冻结清单，不能仍称为“22张修订实验”。

### 可选的激进扩展（不并入首轮默认方案）

若学习者确实要测试不确定修改的净收益，另设 C 组：明确修订加不确定修订；与 B 组相比回答“不确定部分是否额外有益”。这需要额外训练预算和明确的不确定项集合，不能混进 B 后失去归因。仅 A/B 一轮不能同时分离补框和改类各自的因果贡献；本轮可先检验整体清洗组合，暂不增加消融组。

## 4. 数据版本与文件设计（仅为后续执行约定）

保留原始数据及冻结 OOF 产物。建议后续独立目录 `reports/train-cleaning-ab-20261027/`：

- `EXPERIMENT_SPEC.md`：学习者确定的命题、范围、实际生效配置、种子、次数、预算、指标和停止规则。
- `change_manifest.json`：源图/标签哈希、案例与预测/GT身份、改前改后、类别/坐标、依据来源（human_verified / agent_adopted），不冒称人工确认。
- `uncertain_cases.json`：待定原因、保持原样的字段，不自动升级为明确结论。
- `dataset/`：隔离的派生标签/数据清单；图片复用或受控复制，不改原像素、不增删样本。3LC train 使用独立的新表/版本，不能覆盖历史表。
- `metrics.json`、`RESULT.md`：统一口径下的对照、逐类差值、成本、不确定性及实际偏差。

仅22张方案的验收：22个标签文件发生预期差异；8行只改类别且坐标字符串不变；14个新增框经边界定稿并通过坐标合法性及重复标注检查；框总数净增14，train仍7852图，原数据、val与test不动。若扩量，计数从冻结清单重算，不沿用该数。

## 5. 训练对照

|组别|训练图片|训练标签|其他条件|
|---|---|---|---|
|A|相同7852图|原始版本|共同固定|
|B|相同7852图|冻结清洗版本|共同固定|

- 推荐一次配对 A/B 作为探索性试验。由学习者决定是重跑两组，还是严格验证兼容后复用历史 A、只训练 B；后者成本低，但历史环境/代码漂移会减弱归因。
- 两组均从相同方式的随机初始化开始，核对实际种子与初始参数；不能让 B 从历史 best.pt 微调而 A 从零训练。
- 模型、轮数/停止方式、batch、优化器实际行为、增强、采样、精度、依赖、数据加载及 checkpoint 选择规则一致。不顺便改 lr、增强或训练时长。
- 如复用历史 baseline，沿用其真实10轮流程和 best 选择规则；如决定换配置，先建立同新配置的 A，不能直接与旧10轮模型宣称只改标签。
- 隔离两组的 run/table/输出，使用冻结的数据版本。当前入口调用 `.latest()`，必须核验实际解析到的 train/val 表 URL 与哈希；仅“相同表名”不足以保证相同输入。
- 单个种子一对结果只作为探索证据，不能据微小改善宣称稳定收益。是否进一步做预定的配对多种子重复由学习者决定；不因结果不好自动追加种子、加训或换模型。

## 6. 评估：避免换尺子

固定 val966 的图片、标签和清单；不因实验结果改 val。其质量仍是工作假设；此前仅排除了与 train 的16个完全重复样本，不宣称它是全新场景独立测试。保持现有划分是为了单变量对照，不在本实验中重划分。

建议的交叉评分表：

|模型|原始train标签评分|同一清洗版train标签评分|固定val966评分|
|---|---|---|---|
|A 原始标签训练|报告|报告|报告|
|B 清洗标签训练|报告|报告|报告|

- A、B都在同一清洗版train标签上评分，才能比较模型变化；同一模型分别按原始/清洗标签评分，用来量化“只换评分标签”的影响。
- 同一图片集的预测可复用以减少推理；历史预测仅在阈值、NMS、max_det、精度和覆盖范围足够且口径兼容时复用，否则后续需另行批准统一推理。OOF自定义评估器结果不能直接混入starter/native对照。
- 两个模型对两套train标签和val使用同一评估实现、匹配方式、类别平均方式、输入与后处理。
- 建议沿用既有项目目标以固定 val AP50 为主，AP50–95及四类AP、P/R为补充；是否如此采用由学习者确定。
- P/R同时报告预先固定工作点的值和必要的PR曲线；阈值在看新结果前确定，两组一致。每个模型自动选择各自最大F1工作点的P/R可附录，但不能把它解释为相同阈值下的改善。
- 比较 train–val 差距时用同一套 train 参考标签、相同阈值/平均方式，并明确 train 是见过的数据，指标不是泛化评估。

## 7. 结果解释与预先确定的判据

执行前由学习者确定主要指标、允许的逐类退步/Precision–Recall取舍、何种差异只记为无明显变化；本稿不代定数值合格线。

- val AP及预定关注项改善，逐类没有不可接受退步：支持该次清洗组合在该配置下有益。
- val改善而train–val差距扩大：仍可能有益，差距不是否决条件。
- 仅train降低而差距缩小：不支持泛化改善，需报告可能的拟合损失。
- 同一模型仅改评分标签就明显变分：存在评价标签变化效应，不能全归功于重新训练。
- 总分不明显变化：小规模修改或训练随机性可能使信号有限，不能单凭一次阴性结果证明标签纠正无效；也不自动加预算。
- Precision降、Recall升：报告取舍并结合AP/PR曲线，不要求事后挑选更有利阈值宣布成功。
- repeated val使用不是独立最终测试；不读取test、不生成submission，不把本地实验收益等同官方成绩或规则认可。未经过实际视觉审查的预测批量转标签属于本实验排除项。
