# 五组2×bus候选：阶梯式conf只读筛选

打开index.html。阶梯：0.25、0.40、0.50、0.60、0.70、0.80、0.90、0.95、0.99。默认0.25复现原报告高候选口径，不替学习者选择用于补标或训练的阈值。

## 操作与显示口径

- 顶部下拉框、±一档及阶梯统计表按钮都可切换conf。筛选采用原始浮点置信度 `confidence >= threshold`，不是四舍五入后的显示数字。
- 原图、缩略图和候选表同时过滤。默认三处展示全部T的达标框；取消“原图及缩略图叠加全部视野”后，三处同时只看当前T，不再让缩略图自动选择不同T。右侧实际2×输入始终只看当前T。
- 下方改用原图缩略图，明确区分“当前叠加范围框数”和“全视野框数”。没有跨视野合并或去重；两框可能对应同一车辆。
- 改conf时尽量保留当前图片、T和所在分页，便于对照。若选“有当前阈值候选”等筛选后，该帧被排除，会明确提示；想保持看同一帧可用“所有train图片”。
- 阈值升高只会隐藏既有框，原始预测全部保留，不裁剪新图、不推理、不重跑NMS、不改标注、不训练、不导出伪标签。
- 绿色为当前达标bus预测，蓝色为原bus标签。原标签可能错漏，不自动作为完整真值。触边框标记只提示截断风险，不自动排除。

仅使用 `../bus-crop-expansion-retry1-20261025/` 已完成的492张train、1239视野、1967个原始bus候选（conf≥.05）。原推理conf=.05、IoU=.7、FP32等参数不变；当前操作只是既有预测的显示过滤。该报告及历史失败目录不修改。没有读取test或重新推理val。

- 新代码：tools/bus_confidence_review.py、.js、.template.html；新增tests/test_bus_confidence_review.py。
- 157项相关测试通过（新33项，原124项），覆盖阈值边界、单调性、框/图片计数、来源身份、URL、独占写入和CLI分派等。
- 浏览器588项断言通过：五组×九档×五筛选、main/gallery/table候选ID一致、13种T范围、保帧/排除提示、快速切档、导航/分页/开关、实际canvas坐标、坏图片清空恢复、内存数据不变；668px无横向溢出。没有逐图人工判框，只对2秒自动浏览作计时检查。

## 后续授权边界

学习者希望看误判能否减少，效果可接受时再考虑train重标及一次试探性训练。这是条件性意向，**本次仅授权阶梯筛选网页，不等于批准自动重标、覆盖原标签、选定阈值、设计实验或启动训练**。待学习者看图反馈后，再明确数据副本/范围、人工判框及去重/截断处理、训练与评估设置。既有val信息参与热区选择，不把同一val上的变化直接当作独立泛化证据。本轮不代做这些核心决定。
