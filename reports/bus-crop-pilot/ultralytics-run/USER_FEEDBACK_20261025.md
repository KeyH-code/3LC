1. **初步支持“2×局部放大能够在本次已看行驶片段中提供有用的bus框候选”**，来源是学习者的实际目视意见，不再只是机器候选变多。文字明确肯定B的471/500/528/534/536/568，加上549的正确bus候选usable，构成正面观察；不把这些笼统的“正确/没问题”全都升级成无需调整的精确框真值。
2. **4×不是在这些样本上越大越好**：有学习者报告的漏检、bus/truck或bus/van重复、需微调等现象。只描述本次观察，不形成全量数据选参或废弃4×的自动决策。
3. **2×也不是零问题**：578明确需调上边界；457分类意见尚有歧义，488没有逐条件文字。不能记作10/10成功或0漏检/0定位问题。
4. 帧471是一个具体的默认阈值候选增益线索：A无bus候选、B有≥.25 bus且学习者写“2×标对”。528/534/536/549的A仍有弱bus候选，不能把弱候选忽略后称“全图完全没输出”。本记录不自动判所有A类别的框均不可用。
