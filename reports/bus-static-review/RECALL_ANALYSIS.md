# Baseline Recall 对比

同一模型收尾 train 收集与 best val966 验证；不是训练期 loss。

| 类别 | Train Recall | Val966 Recall | 差距（百分点） |
|---|---:|---:|---:|
| truck | 0.77347720 | 0.60000002 | 17.347717 |
| car | 0.90664309 | 0.80775392 | 9.888917 |
| van | 0.74703133 | 0.61269844 | 13.433290 |
| bus | 0.93066585 | 0.74743325 | 18.323261 |
| all | 0.83945435 | 0.69197142 | 14.748293 |

差值按原始精度计算；Recall 两列为0–1，差值为百分点。

- 仅发现候选，不是漏标概率，不生成新框或修改原标签。
- MVI/帧号仅为命名线索，机位及时间未核实；同位置不等于同一辆静止车辆。
- val 信息参与检索；不把同一 val 上后续改善当作独立泛化证据。竞赛训练用途另行确认。
- Recall 只针对已有标注，差距不能估计漏标率或确定根因；P 接近不能排除错漏标。
- 归档没有证明 train/val P/R 使用同一置信度工作点。
- 本轮没有人工结论；不外推全量，不自动补标、训练、推理或推广类别。
